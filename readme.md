# 🚀 Teachboard

O **Teachboard** é uma landing page moderna e minimalista desenvolvida durante o [Curso de HTML e CSS: ambiente, estrutura e estilo](https://cursos.alura.com.br/course/html-css-ambiente-estrutura-estilo) da Alura. O foco do projeto foi aprender e aplicar conceitos básicos de HTML, CSS e responsividade.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica.
* **CSS3**: Estilização com Flexbox.
* **Google Fonts**: Utilização da família *Poppins* (pesos 100 a 900).
* **Responsividade**: Implementação de breakpoints para Mobile, Tablet e Desktop.

---

## 🎨 Design e Funcionalidades

* **Interface Dark Mode**: Estética moderna utilizando tons escuros (`#0E1014`) e roxo vibrante (`#9747FF`).
* **CTA (Call to Action)**: Botão de teste interativo com efeito *hover*.
* **Layout Flexível**: Centralização de conteúdo utilizando CSS Flexbox para melhor adaptação em diferentes telas.
* **Escalabilidade**: Adaptado para telas de:
    * **Desktop**: Layout espaçoso e hierarquia clara.
    * **Tablet (768px)**: Ajustes de margem e largura de texto.
    * **Mobile (375px)**: Redimensionamento de fontes e imagens para dispositivos pequenos.
